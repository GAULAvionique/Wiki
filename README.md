# Wiki de l'Avionique du GAUL
Bonjour! Voici le wiki pour la division avionique du GAUL. L'objectif de ce wiki et de regrouper la documentation, l'information, et les leçons apprises dans un endroit bien organisé et facilement navigable. Les "grosses données" comme les vidéos et données de vol vont rester sur le Teams.
# Installer
Le wiki est géré avec Obsidian et Git. Pour pouvoir lire et interagir correctement avec le wiki, il font donc installer ces logiciels et cloner le répertoire localement :
```bash
git clone https://...
```
On gère les modifications comme on gère les modifications dans du code (effectuer une pull request):
```bash
git add ./fichiers/modifiés
git commit -m "message de commit expliquant les modifications"
git switch -c nouvelle_branche
git push -u origin nouvelle_branche
```
# Collaboration
Ce Wiki se veut collaboratif. Tous les membres du GAUL sont encouragés à y participer, à y ajouter leurs connaissances et à y documenter leurs projets. On prends ici la même approche que pour le développement logiciel: soit travaillez sur une nouvelle branche, et demander une pull request quand vous êtes prêt à ajouter vos modifications à la branche principale.
